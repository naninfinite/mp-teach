# Starting point: rusty C#, forgotten 2D arrays

The learner used 2D arrays in C# about 6 years ago and could get the results they wanted then, but says they now remember "basically 0". Their mental model was "arrays inside arrays". JavaScript is rusty. Treat them as a near-beginner who will recognise things quickly: start from `grid[row][col]` and nested loops, and frame JS syntax against C#.
