# Mission: Matrices, from grids to graphics

## Why
For fun. Rebuild (and go past) what I once knew about matrices by building small grid games I can see and play with, and pick up JavaScript along the way.

## Success looks like
- Build the logic for tic-tac-toe, Connect Four and Minesweeper on a 2D array from scratch
- Build a working Conway's Game of Life and Snake in the browser
- Generate a maze on a grid and solve it with a pathfinding algorithm
- Later: flip/rotate/blur an image's pixel grid, and spin a shape with a rotation matrix

## Constraints
- Daily 10–30 minute sessions, alongside other learning
- Prefers reading + hands-on practice; videos only occasionally
- Rusty C# background (did 2D arrays ~6 years ago); learning JavaScript at the same time

## Out of scope (for now)
- Heavy linear-algebra theory (determinants, eigenvalues, proofs) unless it becomes useful
- Frameworks (React etc.) — plain browser JavaScript only
