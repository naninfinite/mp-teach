Lesson 1 · Tic-tac-toe · ~20 min

Your first grid

A tic-tac-toe board is an array of arrays. Learn to read it, walk it, and spot a winning row.

Today's win: you'll write rowWins(board, row), the first real piece of a tic-tac-toe game. It checks whether a row holds three of the same mark.

1. A grid is an array of arrays

You remembered matrices as "arrays inside arrays", and that's exactly right. In JavaScript, a grid is an outer array whose items are the rows, and each row is an array of cells (javascript.info, MDN):

const board = [
  ["X", "O", "" ],   // row 0
  ["",  "X", "" ],   // row 1
  ["O", "",  "X"],   // row 2
];

Reading a cell takes two steps. board[2] gives you the whole bottom row, ["O", "", "X"]. Then [0] picks the first cell of that row:

board[2]      // ["O", "", "X"]   a whole row
board[2][0]   // "O"              row 2, then column 0

Row first, then column, every time. Picture "down, then across". Counting starts at 0, so a 3×3 board has rows and columns 0, 1 and 2.

Coming from C#: C# has two kinds of 2D array, rectangular string[,] (read with board[2, 0]) and jagged string[][] (read with board[2][0]) (Microsoft Learn). JavaScript only has the jagged kind. There are no types to declare, and const only stops you pointing board at a different array. You can still change the cells inside it (MDN).

Practice · find the cell

2. How big is it?

An array's .length tells you how many items it has. The outer array's items are rows, and each row's items are cells:

board.length      // 3  → number of rows
board[0].length   // 3  → number of columns (cells in row 0)
Coming from C#: it's .length in lowercase, where C# uses .Length. There's no GetLength(1) either. You ask a row how long it is.

3. Visiting every cell

To look at every cell, loop over the rows, and inside that, loop over the columns of the current row. It's the same nested loop you wrote in C#, with let in place of int:

for (let row = 0; row < board.length; row++) {
  for (let col = 0; col < board[row].length; col++) {
    console.log(row, col, board[row][col]);
  }
}
// 0 0 X
// 0 1 O
// 0 2
// 1 0          …and so on, row by row

To compare a cell with something, use === (three equals signs). It's JavaScript's strict equality, and it behaves like C#'s == for strings (MDN). Plain == also exists in JavaScript, but it quietly converts types first, so avoid it.

Exercise 1 · count the marks

Write countMarks(board, mark), which returns how many cells equal mark. On the board above, countMarks(board, "X") is 3. Tip: Ctrl+Enter runs the tests.

4. A winning row

A row is a win when all three of its cells hold the same mark. There's a trap: ["", "", ""] is also "three of the same", but nobody has won. An empty row must never count.

Inside a function that's given row, the cells you care about are board[row][0], board[row][1] and board[row][2]. The row index stays fixed and the column index moves.

Exercise 2 · today's win

Write rowWins(board, row). It returns true if every cell in that row is the same mark and isn't empty, and false otherwise.

Exercise 3 · stretch: flip it

Now write colWins(board, col) for a vertical win. Before you type, ask yourself which index stays fixed this time and which one moves.

5. Check yourself

Answer these from memory, without scrolling up. Retrieving it is what makes it stick.

In board[2][0], which number picks the row?

  1. The 2
  2. The 0

Row first, then column. board[2] is the whole row, and [0] then picks a cell from it.

A Connect Four board has 6 rows and 7 columns. What is board.length?

  1. 7
  2. 1
  3. 6
  4. 3

The outer array holds the rows, so its length is the number of rows. The columns are board[0].length.

Which is the bottom-right cell of a 3×3 board?

  1. board[3][3]
  2. board[2][0]
  3. board[0][2]
  4. board[2][2]

Counting starts at 0, so the last row and the last column are both index 2. board[3] doesn't exist and gives undefined.

What does board[1] on its own give you?

  1. every cell in col 1
  2. every cell in row 1

One index picks one item from the outer array, and those items are whole rows. A column has no array of its own, so you collect it with a loop like the one in colWins.
