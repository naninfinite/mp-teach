Reference · grids (2D arrays) in JavaScript

Grid cheat sheet

Everything you need to make, read and walk a grid. Grows with each lesson.

Make one

const board = [
  ["X", "O", "" ],   // row 0
  ["",  "X", "" ],   // row 1
  ["O", "",  "X"],   // row 2
];

Read and write

CodeGives youNotes
board[r][c]one cellRow first, then column ("down, then across"). Indexes start at 0.
board[r]a whole row (an array)A column has no array of its own, so you collect it with a loop.
board[r][c] = "X"sets a cellWorks even with const board. const only stops you reassigning board itself.
board.lengthnumber of rows
board[0].lengthnumber of columns
board[3] on a 3-row gridundefinedSo board[3][0] throws a TypeError. Last index = length − 1.

Walk it

Every cell

for (let row = 0; row < board.length; row++) {
  for (let col = 0; col < board[row].length; col++) {
    board[row][col]   // …do something
  }
}

One row: fix the row, move the column

board[row][0], board[row][1], board[row][2]

One column: fix the column, move the row

board[0][col], board[1][col], board[2][col]

A winning line

const first = board[row][0];
if (first === "") return false;          // an empty line isn't a win
return board[row][1] === first && board[row][2] === first;
