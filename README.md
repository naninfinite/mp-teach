# mp-teach: Matrices, from grids to graphics

A self-paced course in matrices (2D arrays) through small JavaScript grid games, building towards image grids and rotation matrices.

**Open the course:** [index.html](index.html) (or the GitHub Pages site).

## Layout

- `lessons/`: one short lesson per file, with in-browser exercises
- `reference/`: cheat sheets
- `assets/`: shared styles and widgets (exercises, quizzes, grid views)
- `answers/`: my exercise answers, downloaded from each lesson
- `games/<name>/`: the games themselves, each built on its own `game/<name>` branch and merged into `main` when finished
- `MISSION.md`, `RESOURCES.md`, `NOTES.md`, `learning-records/`: course state

## Roadmap

Tic-tac-toe → Connect Four → Minesweeper → Game of Life → Snake → maze generation and solving → image grids → rotation matrices → (later) fragment shaders
